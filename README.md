# app-rickandmorty

App Android temático de **Rick and Morty** — exercício de UI com Material Components.

## Objetivo

Praticar construção de telas Android (layouts, componentes Material) usando a temática da série.

## Tecnologias

- Kotlin
- AppCompat, Material, ConstraintLayout
- Gradle 8.0 / compileSdk 33 (minSdk 21)

## Pré-requisitos

- **JDK 17**
- Android SDK Platform **33**

## Como rodar

```bash
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties   # macOS
./gradlew assembleDebug
```

Ou abrir no Android Studio e executar `MainActivity`.
